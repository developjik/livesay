What does a streamed answer do to a screen reader?

Thinking…

What this page does

  • Writes every token straight into aria-live="polite", so each word is a speech event.
  • Puts tool status in an assertive region, cutting off whatever was being read.
  • Never says the answer is finished. role="status" stays on “Thinking…”.
  • On failure it just stops: no announcement, no error, no cue.

This is what a default streaming chat UI looks like to a listener. Audit it:

npx livesay audit http://127.0.0.1:4319/bad.html --budget "announcements<8,no-silent"
